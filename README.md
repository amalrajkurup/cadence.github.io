# cadence
Group of apps — privacy policies hosted on GitHub Pages.

- Home: https://amalrajkurup.github.io/cadence/
- Tutor Pay: https://amalrajkurup.github.io/cadence/tutorpay/

## Adding an app
1. Create a folder named after the app, e.g. `myapp/`, and put its policy in `myapp/index.html`.
2. Add a card for it in the root `index.html` (copy the existing `<li>`).
3. Commit and push. The policy URL is `https://amalrajkurup.github.io/cadence/myapp/`.
